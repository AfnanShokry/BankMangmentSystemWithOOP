# Bank Management System & ATM Simulation 🏦🏧

نظام متكامل مبني بلغة C++ يعتمد على واجهة سطر الأوامر (Console) لإدارة العمليات المصرفية ومحاكاة نظام الصراف الآلي (ATM). تم بناء المشروع بتطبيق متقدم لمفاهيم البرمجة الكائنية التوجه (OOP) للحصول على كود نظيف وقابل للتطوير.

## ✨ الميزات الأساسية (Features)

### 1. نظام إدارة البنك (Bank System)
- **إدارة العملاء:** إضافة، تعديل، حذف، والبحث عن بيانات عملاء البنك.
- **العمليات المالية:** الإيداع، السحب، وتحويل الأموال بين الحسابات.
- **إدارة المستخدمين:** نظام صلاحيات دقيق (Permissions) للتحكم في وصول المستخدمين لشاشات معينة بناءً على دورهم (Admin / User).
- **سجل الدخول (Login Register):** تتبع وتسجيل حركة دخول المستخدمين للنظام وتخزينها.

### 2. محاكاة الصراف الآلي (ATM System)
- تسجيل دخول منفصل للعملاء باستخدام رقم الحساب ورمز الـ PIN.
- السحب السريع (Quick Withdraw).
- الإيداع والسحب العادي.
- الاستعلام عن الرصيد.

## 🛠️ التقنيات والمفاهيم المستخدمة (Technologies & Concepts)
- **لغة البرمجة:** C++
- **بيئة التطوير:** Visual Studio
- **المفاهيم البرمجية:**
  - **Object-Oriented Programming (OOP):** الاعتماد المكثف على الكلاسات (Classes)، الوراثة (Inheritance)، التغليف (Encapsulation)، والدوال الافتراضية (Virtual Functions).
  - **معالجة البيانات:** تنظيم بنية البيانات وإدارة الملفات النصية لحفظ واسترجاع بيانات العملاء والمستخدمين.
  - **التحقق من صحة المدخلات (Input Validation):** لضمان عدم حدوث أخطاء عند إدخال بيانات غير منطقية من قبل المستخدم.
